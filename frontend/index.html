    Telegram needs three credentials: an API ID, an API Hash (from your developer account) and a Bot Token (from @BotFather). Follow the steps below.

    1

    API ID & API Hash

    1. Open my.telegram.org in your browser.
    2. Sign in with your Telegram phone number (include the country code, e.g. +212...).
    3. Enter the login code Telegram sends you inside the app.
    4. Click "API development tools".
    5. Fill the short form (app title and short name are enough).
    6. Copy "App api_id" and "App api_hash" into the fields below.
    Open my.telegram.org
    2

    Bot Token

    1. Open Telegram and search for @BotFather.
    2. Send /newbot and choose a name and a username ending in "bot".
    3. Copy the token BotFather returns (looks like 123456:ABC-DEF...).
    4. Add the bot as an administrator of your destination channel.
    Open @BotFather
    3

    Channels

    • Source: the channel to read from — the user account must have joined it.
    • Destination: the channel to post into — the bot must be an admin there.
    • Use @username for public channels, or the numeric ID (e.g. -1001234567890) for private ones.
